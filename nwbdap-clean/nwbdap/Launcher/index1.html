    About the platform

    Each service is an independent terminal that runs on its own. This page is the launcher that ties them into one suite: choose any service to open its full hosted dashboard in a separate browser tab, while this five-service hub stays open here.

    Data maturity differs by service and is labelled on each card. Some run on live feeds (Sentinel-2, NASA POWER, OpenWeather); others currently run on demonstration or illustrative data while their live sources are wired in. Nothing here is an operational warning system or investment advice.

    National Weather Big Data Analytics Platform — a student suite of five weather-and-earth-observation terminals for India. Data sources vary by service (IMD, NASA POWER, Sentinel-2, OpenWeather, CWC, Mapbox) and several services use modelled or illustrative data where noted. Not an official forecasting, emergency-response or investment service.
